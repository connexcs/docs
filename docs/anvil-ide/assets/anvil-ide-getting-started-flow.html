Anvil IDE — Setup Flow

Click a step to expand it. Pick a sign-in method to see the status bar update.
Signing in Selecting a project
1 · Signing In
1
Log in to your Control Panel
▸
Sign in to your ConnexCS account at the standard Control Panel URL, as you would for any other module.
2
Click "Anvil IDE" in the left menu
▸
A new browser tab opens and redirects you to code.connexcs.com, the hosted IDE.
3
Click "Sign In to ConnexCS"
▸
On first launch, the ConnexCS panel on the left sidebar prompts you to authenticate.
4
Choose a sign-in method
▸
Two options are offered in the sidebar. Pick one below — it's remembered for this session.
Sign in via BrowserOAuth window · recommended for most users
Sign in with API TokenPaste a ConnexCS API token directly
5
Signed in ✓
▸
Your files load, and the status bar at the bottom shows your active project.
2 · Selecting a Project
6
Welcome panel appears
▸
Only shown if you haven't selected a project yet this session.
7
Search or browse for a project
▸
→ Search & select from your existing ConnexCS projects
→ Browse recently used projects
8
File explorer populates
▸
Shows all project files: scripts, templates, frontend components, and other resources.
9
Switch projects anytime
▸
Click the project name in the status bar, or use "Switch Project" in the ConnexCS sidebar.
● no project selected auth: not signed in
